# Next.js Login Page

A simple **Next.js login page** with password validation and welcome/logout functionality. This project demonstrates:

- Frontend-only login authentication using a hardcoded user list.

## Setup

### Prerequisites

- Node.js 20.17.0
- npm 10.8.3
- Next.js 16.0.3

### Steps

1. **Clone the repository**
```bash```
git clone
cd login

2. **Install dependencies**
```bash```
npm install

3. **Start the development server**
```bash```
npm run dev

- Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
